# Interop vectors

Every macula 12 stack checks itself against the same bytes. These are copied
unchanged from macula-go v0.12.0's `testdata/` directories, which carry
macula's own: most were generated by macula v12.1.0 on OTP 28 (each file names
its generator), and `identity/lamps_mldsa87_rsa4096_pss_sha512/` holds the LAMPS
draft's vector for id-MLDSA87-RSA4096-PSS-SHA512 as macula v12.7.0 carries it.

| Directory | What it pins |
|-----------|--------------|
| `wire_1_0/` | the wire 1.0 conformance vectors (macula#97), copied unchanged from macula v15.0.0-rc.2's `priv/vectors/wire_1_0/` with the spec page `WIRE_1_0.md` they make executable: the frame envelope, frames, enums, records for readers and custodians, check order, tbs bytes, `_dht.*` shapes and handshake transcripts. Every class runs in `cargo test` |
| `cbor/` | the decoding rule every stack applies to what a peer sends |
| `identity/` | TLS and CONNECT bindings, status statements, the LAMPS composite, and identity layout v1's stored-identity paths, refused names and old-key moves (`identity_layout_v1.json`, copied unchanged from macula v14.4.0's `test/vectors/`) |
| `record/` | own-namespace procedure advertisements and their verdicts, copied unchanged from macula v15.0.0-rc.2's `test/fixtures/own_namespace/` (wire 1.0 records, macula#100) |
| `manifest/` | content manifests and their ids |
| `seal/` | E2E seal scheme 1's recipient keys and ids, and keyed procedure advertisements signed by macula with their verdicts, copied unchanged from macula v13.3.0's `test/vectors/e2e_seal_v1.json` and macula v15.0.0-rc.2's `e2e_seal_v1_advertisements.json` (wire 1.0 records, macula#100) |
| `group/` | sealed groups (macula 13.2): the `group_keys_v1` CALL a member pulls with, the RESULT a distributor answers, the org's `group_keys` grant with the verdict macula's `macula_ucan:authorize/3` reaches on it, and the refusal names, copied unchanged from macula's `test/vectors/e2e_seal_v1_group_keys.json` (the same bytes macula-go v0.27.0-rc.3 carries in its `group/testdata/`) |
| `ucan/` | UCAN_V1: tokens, policies and contexts with their verdicts, proof ids, did:key keys and the narrowing table, copied unchanged from macula v14.5.0's `test/vectors/ucan_v1.json` and its contract `UCAN_V1.md`, among them the did:key length bound (`did_key_length`, macula#87) |
